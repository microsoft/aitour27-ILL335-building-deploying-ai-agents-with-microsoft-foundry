# Lab Modules

Step-by-step instructions for each phase of the lab. You play the role of an **AI developer on Caldova's commercial digital and customer engagement team**, building a B2C consumer sentiment analysis application for **Caldova**, Microsoft's fictional global pharmaceutical company.

| Phase | Module | Duration | Description |
|-------|--------|----------|-------------|
| 0 | [Setup](../setup/SETUP.md) | 10 min | Environment setup and authentication |
| 1 | [Discover Models](lab1-discover-models.md) | 10 min | Navigate the Foundry portal and explore the model catalog |
| 2 | [Verify Setup](lab2-verifysetup.md) | 10 min | Verify the Foundry project and provisioned resources |
| 3 | [Connect & Infer](lab3-connect-and-infer.md) | 12 min | SDK setup, authenticate, and send your first inference |
| 4 | [Sentiment Analysis](lab4-sentiment-analysis.md) | 20 min | Build Caldova's consumer sentiment analysis pipeline |
| 5 | [Model Comparison](lab5-model-comparison.md) | 15 min | *(Self-paced extension -- not included in 75-min session)* Compare outputs across models |
| 6 | [Deploy Agent](lab6-deploy-agent.md) | 15 min | Deploy sentiment analysis as a direct-code hosted agent; optionally generate an evaluation suite |
| 7 | [Summary](lab7-summary.md) | 5 min | Summary, Q&A, and next steps |
| - | [Cleanup](../cleanup/CLEANUP.md) | 5 min | Remove Azure resources |
